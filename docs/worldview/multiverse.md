# ♾ Multiverse

The philosophy of PhantaSpace is a multiverse. The earth is the base of consensus. Different games and NFT developers can develop in their own orthogonal dimensions. Users will have the freedom to choose which dimension to subscribe to. In the time of the mixed reality future, the world is your screen, and the dimension is the website for web3. The purpose of PhantaSpace is to create a set of rules that everyone agrees on, decentralize ownership, and benefit the community.

Each user can have their own dimensions like youtube channels. Users can subscribe to desired dimensions. If there are two objects collide at the same position from different dimensions, the content will be ranked by the Phanton value deposited on the object. The object with the highest Phanton will have priority to be shown above other objects. Check out NFT ranking on [phanton.md](../token-owner-guide/phanton.md "mention").

The multiverse dimension system is still in construction.
